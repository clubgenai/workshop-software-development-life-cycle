# workshop-software-development-life-cycle

Workshop du Club GenAI : **Intégrer l'IA dans son SDLC**.

- Présentation en ligne : https://clubgenai.github.io/workshop-software-development-life-cycle/
- Sources de la présentation : [`presentation/index.html`](presentation/index.html)

La présentation est publiée automatiquement sur GitHub Pages à chaque push sur `main` qui modifie `presentation/`
(voir [`.github/workflows/pages.yml`](.github/workflows/pages.yml)).

## Présenter

Flèches ou espace pour avancer, `F` pour le plein écran, `N` pour les notes de l'orateur.

## TP

```bash
git clone https://github.com/clubgenai/workshop-software-development-life-cycle.git
cd workshop-software-development-life-cycle
git checkout tp
cd erp
npm install
npm run dev
```

L'ERP RH (la CVthèque) s'ouvre sur http://localhost:3000. Détails, API et données : [`erp/README.md`](erp/README.md).
